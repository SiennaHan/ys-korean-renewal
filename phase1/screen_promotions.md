# 화면 승격 이력 — `_snapshots/` 와 `screens_ref/` 가 갈라진 곳

두 폴더의 뜻이 다르다.

| | 무엇 | 규칙 |
|---|---|---|
| `app/src/screens_ref/` | **대조의 기준.** `pnpm parity:activity` 가 이것과 견준다 | 정본이 앞으로 나가면 여기를 다시 뜬다 |
| `phase1/_snapshots/` | **시점 기록.** 처음 목업을 떴을 때의 날것 | **덮어쓰지 않는다** |

그래서 둘은 **앞으로 영원히 갈라진다.** 갈라지는 것 자체는 잘못이 아니고,
**왜 갈라졌는지 적히지 않은 것**이 잘못이다. 아래 표가 그 기록이고,
`check_docs.py` 의 `[화면 승격]` 이 표에 없는 화면을 잡는다.

전에는 이 표가 `check_docs.py` 안의 `TWIN_ALLOW` 라는 파이썬 사전이었다.
검사 이름도 `[목업 쌍둥이]` 로 "둘이 같아야 한다" 는 뜻이었는데, 실제로는
승격할 때마다 항목이 하나씩 느는 **장부**였다. 2026-08-26 에 이름과 자리를
하는 일에 맞췄다.
