손볼 것 · 게임 넷

VocaShot 말고 나머지 — 무슨 게임이고, 무엇이 어긋나 있나

as-is(games_asis_v1.html)는 목록에서 보이는 것만 옮겼다. 이 문서는 게임 안으로 들어가서 규칙을 읽고, 고쳐야 할 것을 적는다. 한 게임씩 채워 나간다. 값은 전부 컴포넌트와 서버 모델 실측이다.

1서울 여행 퍼즐 — 문장 조립

서울의 장소를 하나씩 여행하며, 친구와의 대화 속 문장을 조각으로 조립하는 게임. 지도에서 장소를 고르고 → 도착 대화를 보고 → 퍼즐 몇 개를 풀면 그 장소가 완료된다. components/main/game/seoul-puzzle.tsx 1222줄.

이 게임은 연세 1권 전용이다 — 화면에 그렇게 쓰여 있다

장소 카드에 연세 1권 {l.unit}이 하드코딩돼 있고(750줄), 그 아래에 그 장소에서 다루는 문법 칩이 붙는다. 장소마다 unit과 grammar[]를 들고 있다.

"게임은 교재와 무관하다"는 말이 이 게임에는 안 맞는다. 진도(learning-record)와는 안 이어져 있지만, 콘텐츠 자체가 1권 과에 맞춰 만들어져 있다. 그래서 1급 학습자용이고 2급 이상에게는 쉬울 것이다.

손볼 것 ① — 틀리는 쪽이 이득이다

오답이면 정답 문장이 그대로 화면에 뜨고, "다시 하기"는 loadPuzzle을 다시 부르며 hintUsed를 false 로 되돌린다. 즉 재시도에 아무 감점이 없다.

어떻게 풀었나받는 XP
일부러 틀리고 → 정답을 보고 → 다시 맞힘25
바로 맞힘20
정직하게 힌트를 쓰고 맞힘10

순서가 뒤집혀 있다. 틀리는 것이 가장 많이 받고, 힌트를 쓰는 정직한 쪽이 가장 적게 받는다. 아무 조각이나 넣고 확인 → 정답을 읽고 → 그대로 다시 넣는 것이 최적 전략이 된다.

고치는 방법은 여럿이다 — 오답 XP를 0으로 두거나, 재시도에 hintUsed를 유지하거나(즉 재시도 정답은 10점), 정답 공개를 재시도를 포기했을 때만 하거나. 어느 쪽이든 "틀리는 게 이득"은 없애야 한다.

손볼 것 ② — XP가 기기를 옮기면 값이 바뀐다

헤더에 {totalXp} XP가 늘 떠 있다. 그런데 서버로는 XP를 보내지 않는다 — 장소별로 보내는 score가 퍼즐 수 × 10이라는 상수다(348줄). 실력과 무관하고 누구나 같은 값이다.

저장할 때   stage_id = 장소id,  score = 퍼즐수 × 10   ← 실제 XP 아님
           _meta.extra = { playerName, currentLoc }  ← XP 없음

불러올 때   totalXp = 완료한 장소들의 score 합   ← 내가 번 XP 가 아니다

진짜 XP는 localStorage에만 있다(seoul-puzzle-v1). 그래서 다른 기기에서 로그인하면 내가 번 XP 가 사라지고 "퍼즐 수 × 10"으로 조용히 바뀐다. 늘거나 줄어들 수 있다.

XP 를 계속 쓸 거면 _meta.extra.totalXp 에 넣으면 된다 — 스키마를 안 바꿔도 된다. 아니면 XP 표시를 없애고 완료한 장소 수만 보여 주는 쪽이 정직하다.

확인해야 할 것 — 정답이 정말 하나뿐인가

채점이 어순 완전 일치다. 한국어는 어순이 비교적 자유로워서 다른 순서도 맞는 문장일 수 있다 — 그러면 맞게 쓴 학습자가 오답 처리된다.

콘텐츠가 서버 DB(ko_seoul_puzzle_step)에 있어서 이 저장소만으로는 실제 문장을 볼 수 없다. 확인하지 않고 단정하지 않는다 — 데이터를 받아 훑어봐야 하는 항목으로 남긴다.

콘텐츠 모델 — 관리자가 고칠 수 있다
