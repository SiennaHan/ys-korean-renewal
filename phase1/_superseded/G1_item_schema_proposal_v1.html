1먼저, 유지해야 할 강점

전면 재설계를 제안하지 않는다. 뼈대가 이미 옳고 아래 네 가지는 그대로 가는 게 맞다.

  • 활동별 시트 분리 — 저작 단위와 시트가 1:1이라 작업 분담·진척 관리가 쉽다. 활동마다 필드가 다른 걸 억지로 한 시트에 합치는 설계보다 낫다.
  • 다국어를 행에 내장(en/jp/cn/vi) — 별도 번역 테이블로 빼지 않은 판단이 옳다. 저작·검수가 한 화면에서 끝나고 다국어 원칙(학습 한국어는 불변, 뜻은 UI 언어)과도 맞는다.
  • 듣기 3층 정규화 — n3_listen_script(지문) → _line(발화·화자·성별) → _repeat(문항). 화자·성별이 분리돼 TTS 목소리 배정이 그대로 붙는다. 손대지 않는 게 좋다.
  • 체인지로그 방법론 — 신구판 페이지 단위 대조, "첫 등장 과" 규칙, 보류 상태 관리. 특히 듣기에서 "정답이 뒤집히는 변경은 새 음원 필수 → 보류"로 판단한 건 정확하다. 문항만 고치면 음성과 어긋나 오답 처리되는 사고가 난다.

2파일 내부 정합성 — 실측 결과

이 콘텐츠 엑셀이 자체 완결된 단일 원본이다(외부 마스터에 의존하지 않는다). 그래서 볼 것은 시트 사이의 정합성인데, 1급으로 실제 대조해 보니 어휘는 건전하고 문법만 문제였다.

어휘 — 참조가 실질적으로 건전하다

n1_word_quiz 1급 114문항의 정답 단어를 n1_word_list(1급 312개)와 맞춰본 결과:

점검결과
정답 단어가 n1_word_list에 존재114 / 114 — 누락 0건
퀴즈의 meaning_en ↔ 원장의 en 일치불일치 2건뿐

즉 명시적 FK 없이도 저작이 원장을 잘 따라왔다. 어휘 쪽은 손댈 필요가 크지 않다 — 아래 §3에서 word_ref를 필수가 아닌 권장으로 낮춘 이유다.

문법 — 태그가 아니라 자유 서술이다

n4_blank_question 1급 70행 중 grammar_focus 고유값이 67개다. 거의 모든 행이 서로 다른 문장이라는 뜻으로, 값이 태그가 아니라 그 문항 전용 설명문이다("받침 O → -을까요 (먹 + 을까요)", "마시다 → 마시 + 어요 → 마셔요" 등).

설명문 자체는 학습자에게 보여줄 값어치가 있으므로 없애자는 게 아니다. 문제는 이것만으로는 "-을까요/-ㄹ까요를 다루는 문항 전부"를 뽑을 수 없다는 것이다. 그래서 ① 과별 문법 커버리지 점검이 불가능하고 ② 복습 큐가 "이 문법이 약하다"로 묶어줄 수 없다.

4제안 — 공통 컬럼 규약

모든 문항 시트가 같은 앞머리 컬럼을 갖고 그 뒤에 활동별 고유 컬럼이 붙는 형태. 기존 컬럼은 거의 그대로 두고 앞뒤로 더하는 방식이라 1급 작업이 살아남는다.

[공통 앞머리]

[공통 참조]  ─ 모두 이 파일 안의 시트를 가리킨다 (외부 마스터 없음)
grammar_tag    G-1-10-01         신설 문법 목록 시트 참조. 복수면 세미콜론 구분  [필수]

[활동별 고유 컬럼]  ─ 기존 그대로 (prompt, selection1~4, answer_index, …)

6권하는 순서

  1. 문법 목록 시트를 만든다 — 1급 grammar_focus 67개에서 대표형을 뽑아 확정. 이게 문항 태그의 기준이 된다.
  2. 공통 컬럼 규약 확정 — §4를 그대로 쓸지, 덜어낼지 판단.
  3. 1급 기존 9시트에 컬럼 추가 + 일괄 변환(§5).
  4. 신설 3시트(플래시카드·미션 대화·자모) 양식 작성 후 1급분 저작.
  5. → 여기까지가 G1 종료. 1급 콘텐츠가 완성되고 2급 저작과 개발 Phase 1이 병렬로 출발한다.
판단이 필요한 것

① 문법 대표형 굵기 — 확정 이형태는 한 태그, 받침 조건은 설명문이 담당. §7에서 원칙 2(동형이의 분리)가 추가로 필요해져 함께 확정  ② 공통 컬럼 중 덜어낼 것이 있는지(word_ref는 권장 등급이라 미룰 수 있음)  ③ distractor_type — 해소 자동 판정되므로 1급부터 적용

7문법 태그 1급 초안 — 작업 결과

확정된 원칙으로 n4_blank_question 1급 70행을 실제로 태깅했다. 산출물: 문법태그_1급_초안_v1.xlsx(문법목록 · 태그 부여된 n4 · 안내 3시트).

1급 문법 항목이 22개로 정리됐다. 과별로 보면 4과에서 시작해 15과까지 고르게 도입되고, 이/가(5→7과)·을/를(8→13과)·-아/어요(7→10과)처럼 여러 과에 걸쳐 재출현하는 항목이 태그 덕분에 처음으로 보인다.

원칙 2가 추가로 필요했던 이유 — 에

"이형태는 한 태그"만으로는 에를 처리할 수 없었다. 교재가 같은 표면형을 서로 다른 과에서 다른 문법으로 가르친다.

태그도입 과예시 문항
G-LOC-EXIST 에 (장소·존재)7과영주가 교실에 있어요
G-TIME 에 (시간)12과아침 일곱 시에 일어나요
G-DIR 에 (방향)14과저는 지금 시장에 가요

이걸 한 태그로 묶으면 12과 커버리지가 7과 문항으로 채워진 것처럼 보인다 — 과별 점검이 무의미해진다. 그래서 원칙 2: 같은 표면형이라도 교재가 다른 과에서 다른 기능으로 가르치면 나눈다를 확정했다. 어휘 쪽 "첫 등장 과" 규칙과 같은 성격의 판단이다.

태깅 과정에서 selections가 세 종류로 섞여 있다는 게 드러났고, 정답 태그와 대조하면 자동 판정이 된다.
