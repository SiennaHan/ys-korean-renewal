03목업을 일부러 벗어난 여섯 곳

v1 §03 이 "구현이 목업과 다르면 목업이 기준" 이라고 못박았다. 아래 여섯은 그 기준을 알고 벗어난 것이다. 이유가 없으면 다음 사람이 목업대로 되돌린다.

무엇목업구현왜
O/X 라벨들은 문장제시 문장 들은 것은 오디오뿐이고 그 글자는 맞는지 가릴 대상이다. 목업 문구가 틀렸다
문항 사이 이동없음진행 막대를 누른다 도크에 이전을 넣으면 주 버튼이 좁아져 목업과 달라진다. 막대는 5px 이라 누를 자리를 23px 로 넓혔다(생김새는 그대로)
지시문 출처—원장(xlsx)이 정본 같은 읽기 활동에서 객관식과 O/X 지시문이 다르다. 실제로 O/X 177문항이 객관식 지시문을 달고 있었다. i18n 의 activity.instr* 는 대비책
녹음 시작·종료누르면 바로2초 준비 · 1초 마무리 마이크보다 사람이 빨라 첫 음절이 잘린다. 녹음 자체는 누르는 즉시 시작하므로 안내를 무시하고 말해도 잃는 것이 없다
마이크 거부전체 화면화면 위 알림 + 다시 시도 설정에서 켜고 돌아왔을 때 있던 자리를 잃지 않아야 한다. 전체 화면짜리는 활동 진입 전부터 막힌 경우로 남겼다
선택지 채점고른 것 하나만틀린 것이 여럿 남는다 맞을 때까지 다시 고르는 기존 동작을 살렸다. 자모 듣고 고르기는 두 번 누르던 것을 한 번으로 바꿨다(다른 활동과 같게)

목업에 없어서 새로 만든 CSS 여덟 — .instruction p · .image-choices · .grammar-note · .catalog-empty · .preview-extra · .canvas-host · .record-card .heard .miss · 진행막대 .seg. 각 규칙 위에 왜 만들었는지 적어 두었다.

04그 밖에 오늘 바뀐 것

무엇내용
콘텐츠 v23 반영 앱은 8/6 이식본에 머물러 있었다. 원장(xlsx)과 앱 JSON 을 잇는 것이 없어서다. app/scripts/build-content.py 가 그 일을 한다 — 원장이 정본이고 JSON 은 산출물이다. 들어온 것: 듣기 375문항의 빈 지시문(5개 언어) · 신판 대사 · n4 가 8열→27열 · 플래시카드 12세트 327장 · 문법 234개
자모 경로 이동 /book/chapter/unit/{scene}/{code} → /learn/jamo/*. 이름도 바꿨다 — listen-repeat2 는 2판이 아니라 다른 활동이고 read-write 는 단어 쓰기다. 명세 §4 와 다르다 — BLOCKERS §2
koreanapi 편입 api/ 로 그대로 들여왔다. 자격증명은 전부 환경변수다. api/IMPORT.md
MY — 게스트 차단 계정 화면이라 게스트는 로그인해야 들어온다. 이걸 넣다가 죽은 경로를 찾았다 — 로그인 화면이 게스트까지 돌려보내서, 로그인 시 게스트 기록을 계정으로 옮기는 migrateGuestData 가 한 번도 쓰이지 않았다
표현클립 다국어 한국어 화면에 영어 안내문이 있었고 신고 사유는 한국어로 박혀 있었다. 12문구를 5개 언어로. 급·과 태그로 클립을 추천하는 안은 접었다 — 10단어 과 하나에 329개 중 221개가 걸려 고르는 데 도움이 안 된다
진행 막대 한 칸 칸이 하나면 늘 꽉 찬 줄이라 어디쯤인지를 말해 주지 못한다. 그리지 않는다
리포트 축 이름 레이더는 번역되는데 바로 아래 칩은 한국어였다. 같은 축을 가리키므로 이름은 앱이 쥔다. 축 이름을 번역하니 레이더가 잘려서 viewBox 를 넓혔다

결정마다 왜 그렇게 했는지 커밋 메시지에 있다 — git log --format='%h %s%n%b' --since='2026-08-20'. 하루 29건이다.

06건드리면 깨지는 것

대상왜
app/src/mockups/ 목업에서 캡처한 마크업이다. 목업 대조의 기준이므로 손으로 고치면 검사가 의미를 잃는다. 그 안의 screens.ts 가 스토리가 읽는 쪽이고 낱개 .html 은 사본이다 — 둘을 같이 고쳐야 한다
app/src/shared/data/n*.json 원장에서 만들어진 산출물이다. 손으로 고치면 다음 생성에서 지워진다
이관한 CSS 넷 app/src/styles/ 의 activity · game · nav · vocashot 넷은 목업의 한 줄 한 규칙 형태를 일부러 지킨다. 포맷터를 돌리면 activity.css 가 1,800줄 부풀어 줄 단위 대조가 불가능해진다 — 그래서 biome 대상에서 빼 두었다
menu_type 값 fill-blank · listen-answer · read-answer 는 DB 값이라 바꾸지 않는다(명세 §2.2). 라우트 이름만 바뀌었다
